# Odamblason Auto Painters website

A responsive four-page static website for Odamblason Auto Painters.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static web server (for example `python -m http.server 8000`).

Pages: Home (`index.html`), Services (`services.html`), About us (`about.html`), Contact us (`contact.html`). The contact form prepares an email in the visitor's mail client; it does not submit to a backend service. The before-and-after comparison and gallery photos are illustrative; replace them with Odamblason's real workshop/customer photos when available.
